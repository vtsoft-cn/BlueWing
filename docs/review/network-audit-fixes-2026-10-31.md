## 验证

- `npm test`：208 项应用测试，覆盖先前修复与新发现。
- `npm run test:vpn:integration`：24 项真实随包 sing-box 集成测试。
- `npm run test:vpn-core`：原生全套；包括实际 sing-box、认证 WireGuard、公司用户态 NAT 和模拟公司链路的双向 IPv4 测试。覆盖首次小 ICMP、64/1500/3072 字节 UDP、2048/8192 字节 ICMP、八路同 IP 对交错分片 UDP，并校验实际进入原生核心及报文内容。
- `npm run build:routing-core`：同时执行分片身份/校验和回归，固定 Go 1.26.8、上游版本及原有功能标签。
- `npm run test:installer`：隔离测试当前安装进程筛选、无关进程保留、恢复顺序、失败保留记录及重试；不结束用户实际进程或修改注册表。
- `npm run test:vpn:state-ui`：真实 preload 与 React 状态、切页、迟到快照、恢复提示和核心中断回归。

## 构建和边界

分流核心为 `1.14.3-bluewing.1`；公司核心为 `bluewing.9-network-audit`。两份二进制各附维护源码归档、上游许可证、来源及 SHA-256 清单；源码副本中的依赖变更通过本地 replace 固定，不修改 Go 模块缓存。

本轮没有登录真实公司网关、重启电脑或实际执行安装卸载。隔离完整链路覆盖真实转发实现，不能替代特定公司服务器和 Windows 重启环境的现场验收。没有改变当前用户正在使用的安装、网络设置或凭据。

安装包：`release-network-audit-fixed/BlueWingConnect-NetworkAuditFixed-Setup.exe`，SHA-256：`b23ce60f4962daf8770c0a38eded428ba8a7c4c2f545f34f84a6fee31312b043`。

`node scripts/verify-network-release.cjs` 已核对包内 72 个应用构建文件、两套核心二进制、2590 个维护源文件的清单、两个源码归档及第三方声明。包内恢复助手对不存在的记录返回成功，对损坏记录返回失败并保留原文件；这两项 CLI 检查不访问真实代理设置。
