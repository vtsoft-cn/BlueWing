## 已修复

1. **凭据存储**：系统加密不可用或失败时拒绝保存，不再回退为 Base64。数据库升级到 schema 3，补充节点认证、私钥、原始配置、自定义请求头、订阅地址、VPN 配置和 WebDAV 备份口令的加密；迁移过程中旧数据库 `.bak` 同样重新加密。无法解密时停止加载，避免把凭据损坏误判为空数据库后覆盖。
2. **备份与恢复**：完整 Windows 迁移备份采用 scrypt + AES-256-GCM，要求 12～1024 字符口令。默认分享及 Android 兼容导出移除凭据并说明恢复限制。本机自动备份、导入前快照使用当前 Windows 用户的系统加密；轮换旧明文自动备份时也加密新 `.bak`。数据库导入改为单次加密原子提交，失败回滚内存。导入不同 WebDAV 服务器或账号时不复用旧密码；预览不展示敏感设置值。
3. **云备份**：WebDAV 拒绝 HTTP 和 URL 内嵌账号密码；云备份正文要求独立口令加密，响应大小与加密封装限制保持一致。
4. **诊断**：所有诊断模式脱敏。原生桥不再启用原始 HTTP 正文/头捕获，提交的密码和验证码不写入日志。保留阶段、状态码等定位信息。
5. **本地控制接口**：Clash 控制 API 每次进程启动生成随机密钥，统一认证所有内部调用；移除通配 CORS。运行配置放在限权目录。
6. **Electron 边界**：开启 sandbox，加入生产 CSP，限制页面导航和权限。所有 IPC 统一检查当前窗口、主框架、页面地址及基础参数边界。实际渲染器测试验证外部窗口不能调用受保护接口，并验证 Windows 系统加密。CSP 哈希按浏览器规则归一化换行，避免 Windows CRLF 阻止首帧脚本。
7. **OpenVPN 配置执行面**：限制可接受指令，拒绝插件、脚本钩子、外部配置和密钥文件包含；校验配置 ID。临时认证和配置文件写入仅当前用户可访问的目录，正常关闭及启动失败时清理。目录 ACL 会移除已有的其他账号显式授权。
8. **依赖与构建**：Electron 固定 44.10.1；更新 Vite、electron-builder 及受影响传递依赖。两个 Go 核心固定 Go 1.26.10，并升级 x/net、x/crypto、gRPC、DHCP、Chi、go-jose 等受影响模块。保留维护源码归档、依赖锁及哈希 manifest。NSIS 模板补丁由构建包装器自动应用，不依赖手工修改 node_modules。
9. **界面回归**：修复新增 SoftEther 时的端口/HUB 初始化、切换接入后详情滚动位置复位、首页出口选择框的 Esc 关闭；验证码提交明确携带接入 ID。未验收的传统接入标记为实验功能。回归脚本更新为当前类型选择器、选择控件和删除入口，并等待异步渲染完成。
10. **开源材料**：加入许可证、版权范围、隐私和安全报告说明；修正 OpenVPN 源码义务及 Wintun 预编译许可的错误表述。收集生产 npm 和 Go 构建依赖许可、记录二进制哈希。替换当前源码中的现场组织名和地址，新增 Windows CI、源码快照导出和公开二进制发行检查。
11. **RAS 凭据传递**：固定脚本通过私有 stdin 管道接收结构化数据，调用 Windows `RasSetCredentialsW` 保存登录凭据和 PSK。rasdial 参数仅保留本应用条目名，取消电话簿 PSK 明文写入。凭据设置失败时停止拨号并清理，正常断开也清理；脚本错误正文不进入应用日志。实现依据 [Microsoft RasSetCredentialsW 文档](https://learn.microsoft.com/en-us/windows/win32/api/ras/nf-ras-rassetcredentialsw)。测试编译原生结构、验证 Unicode 管道和无秘密 argv，并以替身验证失败清理；没有在用户电脑创建 VPN 条目或写入真实系统凭据。

## 公开源码与历史

`npm run public:source` 生成 `release-public-source/BlueWing-source.zip`，包含当前维护源码及许可，不包含 `.git`、运行数据、第三方 EXE/DLL/规则或历史源码 ZIP。核对归档中必需的构建配置及两份核心源码均存在。应将审阅后的快照导入新的公开仓库；不要直接镜像当前私有历史。

CI 对纯源码快照执行安全、原生、界面及构建验证；依赖完整规则包的应用/集成回归仅在包存在时运行并明确记录缺失状态。纯源码 CI 成功不能替代完整运行版验收。

对现有 101 个提交的 gitleaks 扫描产生 38 个候选命中：36 处与固定公开上游源码/示例一致，另外 2 处来自本地测试 fixture。当前 WireGuard 校验 fixture 改为运行时生成测试值。这一自动扫描不能代替对现场记录和所有历史内容的人工复核，也不能检测所有形式的凭据。历史中的内部网段和组织名仍存在，未在本轮改写。
